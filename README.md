# FuturePath AI
### An AI-Powered Internship Matching and Career Readiness Platform

## Project Overview
FuturePath AI is an AI-powered web platform designed to help university students and fresh graduates find suitable internship opportunities. It analyzes students' skills, education, interests, and career goals to recommend relevant internships, identify skill gaps, and provide personalized learning roadmaps and career guidance.

## Key Features
- AI-Powered Internship Matching
- AI-Based CV Analysis
- Smart Skill Gap Analysis
- Personalized Learning Roadmap
- AI Career Guidance Assistant
- Internship Application Tracking
- Internship Eligibility Checker
- AI Interview Preparation
- Personalized Job Role Suggestions
